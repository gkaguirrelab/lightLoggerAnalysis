# Light Logger Analysis Data

This directory contains calibration inputs, processed calibration measurements, and supporting data used by the light logger analysis pipeline.

## `ASM7341_spectralSensitivity.mat`

Spectral sensitivity functions for the first 10 channels of the "minispect" chip. These values were taken from the spreadsheet "AS7341_Filter_Templates.xlsx" which was supplied by the manufacturer. The values in this table correspond to Figures 18 and 19 of the white paper AMS Datasheet DS000504 "AS7341; 11-Channel Multi-Spectral Digital Sensor; v3-00 • 2020-Jun-25"

## `empircalAGC.mat`

The output of an analysis of empirical light logger recordings. Recordings from multiple tasks / subjects were analyzed to find the low-pass temporal filter that best related environmental illuminance (as recorded by the minispect) to camera sensitivity (the product of the AGC settings). These data are generated by [`deriveEmpircalAGCAndIlluminance.py`](../code/defineWorldCameraCalibration/deriveEmpircalAGCAndIlluminance.py) and plotted by the routine `defineAGCToMeanLuminance.m` to be compared to measurements made within the light integrating sphere.

The file contains a MATLAB struct named `empiralAGC` with two matched linear-scale column vectors:

- `cameraScoreLinear`: the camera sensitivity score, calculated as analog gain × digital gain × exposure.
- `msIlluminance`: the corresponding temporally filtered minispect illuminance in lux.

To regenerate the file from the checked-in processed-data cache, run:

```bash
python code/defineWorldCameraCalibration/deriveEmpircalAGCAndIlluminance.py
```

## `fullWellCapacityEffect`

[`camera_linearity_ND0_ND0p4_rgb_means.mat`](camera_linearity_ND0_ND0p4_rgb_means.mat): full-well capacity effect calibration data. We measured the CombiLED with the IR filter in the optical pathway, made measurements at 0 and 0.4 NDF with AGC set for 0.4 NDF, 0.5 contrast, and 127 value, then measured both NDFs across a variety of CombiLED setting levels. We fit a correction with `fitFullWellCapacityEffect.m` and derived an exponent from this. This is the data used to do that fitting.

Raw data location: `FLIC_admin/Equipment/ArduCam B0392 IMX219 Wide Angle M12/radiometricCorrectionRGB`

### Generation workflow

The raw world-camera linearity recordings were collected through [`collect_light_logger_calibration_data.m`](../code/collectRadCal/matlabCode/collectMeasurements/collect_light_logger_calibration_data.m). The collection included ND 0 and ND 0.4, ten CombiLED levels from 0.1 through 1.0, three repeated measurements, and fixed camera settings with AGC disabled. The acquisition call had the following form:

```matlab
NDFs.world_linearity = [0, 0.4];

collect_light_logger_calibration_data( ...
    experiment_name, device_num, sensor_ids, NDFs, ...
    calibration_metadata, upload_video_data);
```

The resulting experiment folder was parsed with [`convert_light_logger_calibration_data.m`](../code/analyzeRadCal/matlabCode/convert_light_logger_calibration_data.m), using `use_mean_frame` together with `differentiate_color`:

```matlab
light_logger_calibration_data = convert_light_logger_calibration_data( ...
    path_to_experiment, ...
    'use_mean_frame', true, ...
    'differentiate_color', true);
```

This parsing step spatially averages the raw Bayer frame separately for the R, G, and B pixel classes while also retaining the overall frame mean. Each parsed world-camera frame therefore has four values in the order `[R_mean, G_mean, B_mean, frame_mean]` rather than a single whole-frame mean.

The converted calibration data were then analyzed with:

```matlab
analyze_light_logger_calibration_data(light_logger_calibration_data);
```

This calls [`analyze_camera_linearity_data.m`](../code/analyzeRadCal/matlabCode/analyze_camera_linearity_data.m), which averages the channel values across frames and repeated measurements, selects the ND 0 and ND 0.4 results, and saves them as `camera_linearity_ND0_ND0p4_rgb_means.mat`. The save operation writes to the current MATLAB working directory; the generated file was subsequently placed in this directory.

## `radiometricCorrectionRGB/`

Directory that contains measurements used to derive the RGB radiometric correction in `defineRadiometricWeights.m`. This includes `CloudySkySPD_37degSolarElevation.mat`, Geoff's PR670 measurement of the cloudy sky outside Goddard Labs when the sun was at 37° elevation, along with IMX219 cloudy-sky frame material. The source of this cloudy sky measurement and the example frames taken from it, can be found in DropBox under `FLIC_data/lightLoggerRadCal/W1P1M1/radiometricCorrectionRGB`.

Raw data location: `FLIC_admin/Equipment/ArduCam B0392 IMX219 Wide Angle M12/radiometricCorrectionRGB`
