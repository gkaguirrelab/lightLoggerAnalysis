# Python MATLAB-I/O Libraries

This directory contains Python utilities that read light logger data and
interoperate with MATLAB calibration routines and MAT files.

## Saved AGC-to-Illuminance Fit

`video_io.camera_scores_to_illuminance` converts the world-camera AGC product

```text
analog gain × digital gain × exposure
```

to the illuminance represented by the camera AGC target. It loads
`derived/cameraAGCToIlluminanceFit.mat`, validates the four fitted coefficients,
and evaluates the continuous two-slope equation in log10 space using NumPy.
Nonfinite or nonpositive camera scores remain `NaN`.

The MAT file is generated by
`code/defineWorldCameraCalibration/utilities/fitCameraAGCToIlluminance.m` from
the empirical calibration point cloud in
`data/empircalAGCAndIlluminance.mat`. The Python function consumes the saved
fit; it does not start MATLAB or refit the camera calibration. This MAT file is
the authoritative coefficient source; there is no duplicate hard-coded fit in
`world_util.py`.

`video_io.video_to_illuminance` calls this conversion once for the camera-score
vector associated with a processed video. It uses the resulting reference
illuminance to scale valid, linearized RGB pixels into lux. Dummy frames,
invalid AGC metadata, and saturated pixels remain `NaN` according to the video
conversion rules.

The same video workflow also converts minispect counts through
`ms_util.ms_counts_to_illuminance`. That is a separate calibration path and
still delegates to MATLAB; it does not alter or regenerate the saved camera
fit.
